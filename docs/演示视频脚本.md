# MemGuardOS 演示脚本

目标时长：3-5 分钟。最终视频必须在 openKylin 上录制。

## 0:00-0:30 开场

MemGuardOS 是面向 Linux/openKylin OS Agent 的记忆系统，重点展示可解释记忆提取、结构化检索、敏感记忆阻断、精准遗忘、审计追踪、本地 Web 控制台和 OS 级集成。

核心表达：

> MemGuardOS 不是普通 RAG 记忆库，而是把智能体记忆视为一种受 OS 管理的资源，具备版本、审计、隔离、资源限制和不可逆遗忘。

## 0:30-1:30 真实 Agent 交互闭环

在 openKylin 终端执行一键入口：

```bash
cd /home/luo/memguardos
MEMGUARD_DEMO_NAMESPACE=video-agent bash scripts/memguard-agent-showcase.sh
```

进入工作台后输入 `/guide`，再按以下顺序操作：

```text
/memory off
/run 请在当前项目中查找 build_agent_context 的定义位置，只报告文件路径和行号。
/memory on
/run 纠正一下：以后搜索代码统一使用 grep，并且回答时先给命令再解释。请重新查找 build_agent_context 的定义位置。
/preferences
/run 按我的日常习惯，查找 forget_agent_interactions 的定义位置。
```

画面需要展示：

- 关闭记忆时明确显示“采用记忆 0 条”，且本次不读写长期记忆；
- 用户纠正后形成 `code_search_tool=grep` 和 `response_order=command_then_explanation`；
- 新会话不重复具体要求，系统仍采用相关记忆；
- OpenHands 实际执行 `grep`，最终答复先给命令再解释；
- 两项偏好作用验证均显示“已观察到并通过”。

2026-07-28 的 openKylin 实跑中，上述流程使用远程 OpenAI 兼容模型成功完成。基线臂实际执行两次 `rg`；学习后的新会话实际执行 `grep`，采用 5 条相关记忆，两项偏好证明均通过。该结果来自 OpenHands SDK 真实会话，不是 `memguard demo` 事件回放。

若现场模型波动，直接展示 `docs/evidence/agent_latest/session_a_events.json` 与对应上下文，并明确这是提前采集的真实运行证据，不伪装成实时成功。

## 1:30-2:15 精准遗忘

继续在同一工作台执行：

```text
/forget 忘掉我关于代码搜索工具的偏好
/forget 忘掉我关于代码搜索工具的偏好 --yes
/preferences
```

展示：

- 预览只命中 `code_search_tool=grep`，不会误删回答顺序偏好；
- 确认后主记录、FTS、图关系、缓存、mmap 明文和审计链验证通过；
- `/preferences` 只保留 `response_order=command_then_explanation`；
- 界面明确提示 MemGuardOS 受管数据与 OpenHands 外部日志、备份的边界。

历史成功命令仍可能作为程序性经验存在，但目标工具偏好不再作为强制规则注入。答辩时应准确表述为“遗忘目标偏好及其治理影响”，不要说成“删除 grep 工具的全部知识”。

## 2:15-2:50 敏感治理与 OS 机制

展示：

```text
=== 3. Sensitive blocking ===
```

讲解：

- API key、token、private key 等模式会被识别。
- `.env`、`.ssh/id_rsa`、`/etc/shadow` 等 OS 路径会提高风险等级。
- 高风险内容不会被写入长期记忆。

补充展示 `memguard-agent@luo.service` 的 `NoNewPrivileges`、`PrivateTmp`、`ProtectSystem`、`MemoryMax` 和 `CPUQuota`，说明 Agent bridge 以普通用户和资源限制运行。

## 2:50-3:25 审计验证

展示：

```text
=== 5. Audit verification ===
```

讲解：

- 关键操作都会写入 SQLite 审计表。
- 审计记录通过哈希链串联，能检测篡改。
- 并发审计写入使用 SQLite 写锁事务保护，openKylin 证据中 72 条并发事件写入后验证通过。
- 在 openKylin/systemd 中，事件也可镜像到 journald。

## 3:25-4:30 指标评测与 SDK

展示 Web 控制台指标总览和两套分开的评测：

```bash
python scripts/evaluate_agent_interactions.py \
  --dataset data/benchmarks/agent_interactions.jsonl \
  --output-dir /tmp/agent-eval
```

重点展示：

- 200 条 Agent 专项的提取、角色污染、敏感泄漏、遗忘和跨会话指标；
- 通用 217 条 benchmark 和 10k 负载 P95；
- Kylin embedding/vector SDK 可选增强；
- 审计链验证和证据包 SHA-256。
