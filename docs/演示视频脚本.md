# MemGuardOS 演示脚本

目标时长：3-5 分钟。最终视频必须在 openKylin 上录制。

## 0:00-0:30 开场

MemGuardOS 是面向 Linux/openKylin OS Agent 的记忆系统，重点展示记忆提取、结构化检索、敏感记忆阻断、精准遗忘、审计追踪和 OS 级集成。

核心表达：

> MemGuardOS 不是普通 RAG 记忆库，而是把智能体记忆视为一种受 OS 管理的资源，具备版本、审计、隔离、资源限制和不可逆遗忘。

## 0:30-1:10 多源记忆接入

运行：

```bash
python scripts/demo_smoke.py
```

展示：

```text
=== 1. Multi-source ingestion ===
```

讲解：

- 用户偏好写入长期偏好记忆。
- Linux/systemd 工作流写入知识记忆。
- 来自 `.ssh/id_rsa` 的敏感 OS 事件被阻断，不进入长期记忆。

## 1:10-1:50 混合检索与图谱检索

展示：

```text
=== 2. Hybrid and graph retrieval ===
```

讲解：

- 检索融合词法评分、轻量向量式评分和图谱扩展。
- `graph-search systemd` 可以通过抽取出的实体命中相关记忆。
- `related <memory_id>` 可以解释记忆之间通过 Linux、systemd、journald 等实体关联。

## 1:50-2:30 敏感阻断

展示：

```text
=== 3. Sensitive blocking ===
```

讲解：

- API key、token、private key 等模式会被识别。
- `.env`、`.ssh/id_rsa`、`/etc/shadow` 等 OS 路径会提高风险等级。
- 高风险内容不会被写入长期记忆。

## 2:30-3:30 精准遗忘

展示：

```text
=== 4. Precise forgetting ===
```

讲解：

- 自然语言遗忘请求先生成候选。
- 确认后写入 tombstone。
- compact 前，追加式段文件历史中可能仍有旧明文。
- compact 后，明文探针无泄漏，证明不可逆清除。

## 3:30-4:10 审计验证

展示：

```text
=== 5. Audit verification ===
```

讲解：

- 关键操作都会写入 SQLite 审计表。
- 审计记录通过哈希链串联，能检测篡改。
- 在 openKylin/systemd 中，事件也可镜像到 journald。

## 4:10-5:00 指标评测

运行：

```bash
python -m memguard.eval.run_eval --latency-size 1000 --latency-queries 120 --output docs/eval_result_openkylin.json --markdown docs/eval_report_openkylin.md
```

重点展示：

- 平均 Recall@5。
- 跨语言 Recall@5。
- 图谱实体 Recall@5。
- 敏感阻断 F1。
- 遗忘候选精确率/召回率。
- 冲突解决正确率。
- P95 延迟。
- RSS 与存储占用。
