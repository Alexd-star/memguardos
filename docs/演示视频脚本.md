# MemGuardOS 演示脚本

目标时长：3-5 分钟。最终视频必须在 openKylin 上录制。

## 0:00-0:30 开场

MemGuardOS 是面向 Linux/openKylin OS Agent 的记忆系统，重点展示可解释记忆提取、结构化检索、敏感记忆阻断、精准遗忘、审计追踪、本地 Web 控制台和 OS 级集成。

核心表达：

> MemGuardOS 不是普通 RAG 记忆库，而是把智能体记忆视为一种受 OS 管理的资源，具备版本、审计、隔离、资源限制和不可逆遗忘。

## 0:30-1:30 真实 Agent 交互闭环

先打开本地 Web 控制台的 Agent 治理页，展示真实事件时间线、偏好证据和三阶段上下文。随后运行：

```bash
.venv-agent/bin/python scripts/run_openhands_memguard_demo.py \
  --namespace video-agent \
  --session-id video-session-a \
  --task "以后搜索代码使用 rg，并先给命令再解释。请查找 build_agent_context。" \
  --max-iterations 8
```

展示：

- 用户消息、Agent 消息、工具调用和工具结果自动进入事件链；
- OpenHands 实际调用终端，而不是播放预制输出；
- 系统自动提取 `rg` 工具偏好和回答顺序偏好；
- 新会话的工具选择与结果生成上下文能够命中这些偏好。

若现场模型波动，直接展示 `docs/evidence/agent_latest/session_a_events.json` 与对应上下文，并明确这是提前采集的真实运行证据，不伪装成实时成功。

## 1:30-2:15 精准遗忘

在 Web Agent 治理页按主题预览“先命令后解释”的遗忘候选，确认后执行。展示：

- 回答顺序偏好从三个阶段上下文消失；
- 事件载荷和 compact 后段文件明文检查通过；
- 无关的 `rg` 工具偏好仍然保留；
- 页面提示 OpenHands 原始会话等外部持久化边界。

## 2:15-2:50 敏感治理与 OS 机制

展示：

```text
=== 3. Sensitive blocking ===
```

讲解：

- API key、token、private key 等模式会被识别。
- `.env`、`.ssh/id_rsa`、`/etc/shadow` 等 OS 路径会提高风险等级。
- 高风险内容不会被写入长期记忆。

补充展示 `memguard-agent@luo.service` 的 `NoNewPrivileges`、`PrivateTmp`、`ProtectSystem`、`MemoryMax` 和 `CPUQuota`，说明 Agent bridge 以普通用户和资源限制运行。

## 2:50-3:25 审计验证

展示：

```text
=== 5. Audit verification ===
```

讲解：

- 关键操作都会写入 SQLite 审计表。
- 审计记录通过哈希链串联，能检测篡改。
- 并发审计写入使用 SQLite 写锁事务保护，openKylin 证据中 72 条并发事件写入后验证通过。
- 在 openKylin/systemd 中，事件也可镜像到 journald。

## 3:25-4:30 指标评测与 SDK

展示 Web 控制台指标总览和两套分开的评测：

```bash
python scripts/evaluate_agent_interactions.py \
  --dataset data/benchmarks/agent_interactions.jsonl \
  --output-dir /tmp/agent-eval
```

重点展示：

- 200 条 Agent 专项的提取、角色污染、敏感泄漏、遗忘和跨会话指标；
- 通用 217 条 benchmark 和 10k 负载 P95；
- Kylin embedding/vector SDK 可选增强；
- 审计链验证和证据包 SHA-256。
