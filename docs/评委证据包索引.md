## 3. openKylin 复现命令

进入环境：

```bash
cd ~/memguardos
source .venv/bin/activate
```

基础验证：

```bash
python -m pytest -q
python -m memguard.cli.memctl doctor
```

1k 负载评测：

```bash
python -m memguard.eval.run_eval \
  --latency-size 1000 \
  --latency-queries 120 \
  --output docs/eval_result_openkylin.json \
  --markdown docs/eval_report_openkylin.md
```

10k 规模评测：

```bash
python -m memguard.eval.run_eval \
  --latency-size 10000 \
  --latency-queries 150 \
  --output docs/eval_result_openkylin_10k.json \
  --markdown docs/eval_report_openkylin_10k.md
```

一键验证：

```bash
bash scripts/openkylin_verify.sh
```

一键采集证据包：

```bash
bash scripts/collect_openkylin_evidence.sh
```

如需同时刷新 10k 规模评测：

```bash
bash scripts/collect_openkylin_evidence.sh --with-10k
```

采集结果会写入 `docs/evidence/openkylin_<时间戳>/`，并同步一份到 `docs/evidence/latest/`。

## 4. OS 机制证据命令

systemd/cgroup：

```bash
sudo bash scripts/install_openkylin.sh "$(pwd)"
sudo systemctl start memguardd
systemctl status memguardd
systemctl show memguardd -p MemoryMax -p CPUQuotaPerSecUSec
cat /sys/fs/cgroup/system.slice/memguardd.service/memory.max
cat /sys/fs/cgroup/system.slice/memguardd.service/cpu.max
```

journald：

```bash
python -m memguard.cli.memctl ingest --text "openKylin journald audit smoke test"
python -m memguard.cli.memctl verify-audit
journalctl -t memguardd -n 50
```

auditd：

```bash
python -m memguard.cli.memctl auditd-rules --format auditctl
sudo bash scripts/install_auditd_rules.sh "$(pwd)"
sudo auditctl -l | grep memguard_sensitive
sudo cat /etc/shadow >/dev/null 2>/dev/null || true
bash scripts/auditd_to_memguard.sh "$(pwd)" memguard_sensitive 200 --summary
```

BPF LSM 可选强制拦截增强：

```bash
python3 scripts/generate_bpf_lsm_policy.py --policy data/demo/bpf_lsm_policy.json --output /tmp/memguard_lsm_policy.generated.h
bash scripts/run_bpf_lsm_enforcer.sh docs/evidence/latest
```

当前结论：

- openKylin 内核 LSM 列表包含 `bpf`，BTF 可用。
- `native/bpf_lsm/` 能完成构建、loader attach 和安全测试。
- `scripts/generate_bpf_lsm_policy.py` 可将 JSON 策略转为可审查的静态 denylist header。
- 访问 `/tmp/memguardos_lsm_secret` 返回 `Permission denied`，证据为 `enforcement_result=denied`。
- 默认不拦 `/etc/shadow`、SSH、sudo 或 PAM 相关路径，避免影响登录链路。

Peony/UKUI 原生插件：

```bash
bash scripts/probe_ukui_deep_plugins.sh docs/evidence/latest
bash scripts/build_ukui_plugins.sh
bash scripts/install_ukui_plugins.sh --no-build
bash scripts/verify_ukui_plugins.sh
```

当前结论：

- `libpeony-dev`、`libukcc-dev` 和 Qt5 开发工具可用。
- Peony 右键菜单插件和 UKUI 控制中心插件已构建出 `.so`。
- 当前 openKylin ostree/overlay 只读 `/usr` 场景已通过 bind mount 演示安装处理；Peony 右键菜单项“发送到 MemGuardOS 记忆安全扫描”已在桌面右键菜单中可见验证。
- UKUI 控制中心入口“MemGuardOS 记忆安全”已在设置界面中可见验证；当前源码已升级为本机运维面板，覆盖运行环境检查、审计链校验、端侧向量能力检查、诊断报告和本地控制台入口。

实现说明见 `docs/Peony与UKUI桌面集成实现说明.md`。

Debian 安装包：

```bash
bash scripts/build_deb.sh
sudo apt install ./dist/memguardos_0.1.0_amd64.deb
memctl doctor
```

当前结论：

- openKylin 上已构建 `dist/memguardos_0.1.0_amd64.deb`。
- 包内容包含 `/opt/memguardos`、`/usr/bin/memctl`、`/usr/bin/memguardd`、`memguardd.service`、`memguardd@.service`、Peony 插件和 UKUI 控制中心插件。
- 离线解包后通过 `PYTHONPATH=/tmp/memguardos-deb-root/opt/memguardos python3 -m memguard.cli.memctl doctor` smoke。
- 当前非维护模式下 `sudo apt install` 被 openKylin `ostree-pkgs-guard` 拦截，属于系统保护策略；进入维护模式后可执行完整安装复验。

## 5. Kylin SDK 证据命令

文本向量化 SDK：

```bash
python -m memguard.cli.memctl sdk-status
python -m memguard.cli.memctl sdk-status --probe-embedding --probe-timeout 180
bash scripts/diagnose_kylin_embedding.sh --no-probe
bash scripts/run_kylin_embedding_probe.sh "openKylin agent memory"
```

当前结论：

- 能检测到 `libkysdk-coreai-embedding.so.1`。
- 能读取 768 维端侧文本模型信息。
- Python 子进程探针和官方 C API 风格 C++ 探针均可返回 768 维向量。
- Kylin embedding 可作为可选重排后端；默认主路径仍采用稳定 FTS/hash/graph，以保证跨环境复现。

向量数据库 SDK：

```bash
bash scripts/run_kylin_vector_probe.sh
```

当前结论：

- 能检测到 `libkysdk-vector-engine-client.so.1`。
- C++ 探针已验证连接、建表、插入、加载、搜索、清理。
