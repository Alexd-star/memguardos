## 3. openKylin 复现命令

进入环境：

```bash
cd ~/memguardos
source .venv/bin/activate
```

基础验证：

```bash
python -m pytest -q
python -m memguard.cli.memctl doctor
```

1k 负载评测：

```bash
python -m memguard.eval.run_eval \
  --latency-size 1000 \
  --latency-queries 120 \
  --output docs/eval_result_openkylin.json \
  --markdown docs/eval_report_openkylin.md
```

10k 规模评测：

```bash
python -m memguard.eval.run_eval \
  --latency-size 10000 \
  --latency-queries 150 \
  --output docs/eval_result_openkylin_10k.json \
  --markdown docs/eval_report_openkylin_10k.md
```

一键验证：

```bash
bash scripts/openkylin_verify.sh
```

一键采集证据包：

```bash
bash scripts/collect_openkylin_evidence.sh
```

如需同时刷新 10k 规模评测：

```bash
bash scripts/collect_openkylin_evidence.sh --with-10k
```

采集结果会写入 `docs/evidence/openkylin_<时间戳>/`，并同步一份到 `docs/evidence/latest/`。

## 4. OS 机制证据命令

systemd/cgroup：

```bash
sudo bash scripts/install_openkylin.sh "$(pwd)"
sudo systemctl start memguardd
systemctl status memguardd
systemctl show memguardd -p MemoryMax -p CPUQuotaPerSecUSec
cat /sys/fs/cgroup/system.slice/memguardd.service/memory.max
cat /sys/fs/cgroup/system.slice/memguardd.service/cpu.max
```

journald：

```bash
python -m memguard.cli.memctl ingest --text "openKylin journald audit smoke test"
python -m memguard.cli.memctl verify-audit
journalctl -t memguardd -n 50
```

auditd：

```bash
python -m memguard.cli.memctl auditd-rules --format auditctl
sudo bash scripts/install_auditd_rules.sh "$(pwd)"
sudo auditctl -l | grep memguard_sensitive
sudo cat /etc/shadow >/dev/null 2>/dev/null || true
bash scripts/auditd_to_memguard.sh "$(pwd)" memguard_sensitive 200 --summary
```

## 5. Kylin SDK 证据命令

文本向量化 SDK：

```bash
python -m memguard.cli.memctl sdk-status
python -m memguard.cli.memctl sdk-status --probe-embedding
```

当前结论：

- 能检测到 `libkysdk-coreai-embedding.so.1`。
- 能读取 768 维端侧文本模型信息。
- 当前 VM 中真实推理超时，因此主路径保留稳定 fallback，不做过度宣称。

向量数据库 SDK：

```bash
bash scripts/run_kylin_vector_probe.sh
```

当前结论：

- 能检测到 `libkysdk-vector-engine-client.so.1`。
- C++ 探针已验证连接、建表、插入、加载、搜索、清理。
