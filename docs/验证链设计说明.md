# 验证链设计说明

## 四种统一结构

`MemoryChangeSummary` 说明一次写入或 Agent 运行带来的新增、更新、阻断和跳过；`PreferenceEffectProof` 说明偏好是否注入以及真实行为是否遵循；`ForgetVerificationReport` 说明受管数据的逐项复核和外部边界；`SensitiveBlockNotice` 说明敏感内容是否进入长期记忆和 RAG。

## 证据等级

1. 真实 Agent：由 OpenHandsMemoryRunner 接收真实事件，保留运行模式、工具结果和原始证据。
2. 本地回放：使用与真实适配器相同的标准事件模型，验证 MemGuardOS 业务链，但不证明外部模型自主完成任务。
3. 只读预览：只构建上下文或遗忘候选，不改变存储。
4. 静态契约：验证 Web 控件、Qt 资源、CLI 参数和文档口径存在，不能替代运行结果。

## 遗忘边界

受管范围包括 MemGuardOS 元数据、FTS、图谱、搜索缓存、段文件和 Agent 上下文选择。OpenHands 原始日志、模型提供商日志、终端历史、虚拟机快照、文件备份和块设备取证不在受管范围。报告必须同时显示“已验证”和“未管理”，不得把逻辑遗忘包装为物理介质清除。

通知验证同样区分“记录”和“打扰”：普通记忆新增、检索和本机智能检索降级只进入通知中心；敏感内容保护、高风险工具拦截、遗忘结果、操作记录异常、服务异常和实际 Agent 偏好更新才允许进入托盘弹窗。托盘按通知编号去重，暂停通知只暂停弹窗，不删除通知中心记录。
