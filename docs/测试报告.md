## openKylin 验证摘要

openKylin 2.0 SP2 虚拟机环境：

- Python：3.12.2
- 内核：`Linux-6.6.0-19-generic-x86_64`
- SQLite：3.42.0
- cgroup v2 可见
- `systemctl`、`journalctl`、`systemd-cat` 可用
- `auditctl`、`ausearch` 已安装并验证
- Kylin embedding SDK 与 vector SDK 均可检测

已完成命令：

```bash
pip install -e ".[dev]"
python -m pytest -q
bash scripts/openkylin_verify.sh
python -m memguard.cli.memctl sdk-status
sudo bash scripts/install_auditd_rules.sh "$(pwd)"
bash scripts/auditd_to_memguard.sh "$(pwd)" memguard_sensitive 200 --summary
```

稳定性修复：混合检索已从 Python 内置 `hash()` 切换为 SHA-256 稳定哈希，避免不同进程随机种子导致候选排序微小波动。

敏感检测增强：新增上下文触发的中文姓名、中文地址、银行卡号、AWS Access Key ID 检测，并保留 `token bucket` 等非凭据场景负例。新增用户行为、API 鉴权、可选 LLM adapter 与 bpftrace 探针后，openKylin 最新证据包验证为 `33 passed`。敏感阻断 F1、脱敏 F1、敏感标签 F1 均为 1.0000。自定义敏感正则现在会经过编译和安全性校验，坏规则被拒绝并写入审计。

困难样例扩充：当前 benchmark 包含 22 条种子记忆、17 条检索用例、18 条敏感检测用例、12 条精准遗忘用例、6 条冲突解决用例、8 条图谱检索用例。新增 fanotify、eBPF、精准遗忘 hard negative、中文偏好定向遗忘、rg/grep 冲突、高风险确认策略冲突、shell 行为历史、上下文 token 预算、UKUI 轻量通知、本地 Agent API 等场景，本地与 openKylin 指标全部通过。

扩充 benchmark 后的 openKylin 10k 规模评测：150 次查询，P95 为 242.053 ms，P99 为 260.004 ms，RSS 为 61296.0 KB，仍明显低于 500 ms 目标。该报告已包含 6 条冲突解决用例。
