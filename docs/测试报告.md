## 真实 Agent 专项验证

openKylin 实证会话 `real-agent-session-a2` 中，用户明确要求使用 `rg` 并先给命令再解释，OpenHands 实际执行了：

```text
rg -n build_agent_context memguard
```

工具结果包含 `memguard/service.py:1362`。系统自动提取 `code_search_tool=rg` 和回答顺序偏好，并在后续会话的工具选择与结果生成上下文中命中。随后对回答顺序偏好执行范围化遗忘，三阶段上下文、事件载荷和 compact 后段文件均验证无相关明文，同时保留无关的 `rg` 偏好。

Agent 交互专项 benchmark 共 200 条，其中 60 条为匿名化真实风格样例，140 条为合成难例。提取精确率、召回率、F1、遗忘成功率和跨会话遵循率均为 `1.0000`，角色污染率和敏感泄漏率均为 `0`，openKylin P95 为 `113.97 ms`。专项 P95 包含每个案例的隔离数据库创建开销，不与 10k 主检索 P95 混用。

在此基础上，项目新增了“记忆是否真正帮助 Agent”的双层评测。16 组确定性配对实验分别比较无记忆、完整历史回放和 MemGuardOS 三种条件：MemGuardOS 组任务完成率为 `1.0000`，无记忆组为 `0.7500`；首选工具准确率由 `0.3846` 提升至 `1.0000`；平均交互轮数由 `2.4375` 降至 `1.0000`；相对完整历史回放，Prompt token 统一估算值平均减少 `61.1264%`。该层使用固定、公开的 JSONL 场景验证系统逻辑和指标计算，不冒充真实模型实验。

openKylin 上运行真实 OpenHands 会话，使用 Ollama `qwen3:1.7b`。原 R01-R12 的 12 组证据保存在 `docs/evidence/memory_value_latest/`，新增 R13-R20 的 8 组扩展证据保存在 `docs/evidence/real_agent_extension_r13_r20_latest/`，新增 8 组 holdout 留出盲测保存在 `docs/evidence/real_agent_holdout_latest/`。28 组均产生完整结果，记忆系统层与 Agent 行为层通过率均为 `1.0000`，未归因失败为 `0`。适配器保留模型原始尝试，并通过偏好执行 Hook、有界合规修复、严格只读结构化意图恢复和程序性结果兜底提高稳定性；恢复事件带有明确来源标记，不冒充模型原生调用。完整说明见 `docs/真实Agent记忆价值评测报告.md`。

## 并发优化与消融实验

并发尾延迟的根因不是向量余弦计算，而是冷查询阶段的候选生成。旧实现即使 FTS 已返回足够候选，仍会无条件读取一批最新记忆，造成候选数量和 SQLite 行反序列化成本重复；批量检索还会为每条查询重新创建服务。当前实现改为按 64 条候选预算逐级使用 FTS、图谱和最新记忆补足，并让每个工作线程复用服务。候选预算实验显示 24、32、48 会降低 Recall@5，64、96、128 均保持 1.0000，因此选择 64 作为不损失召回的最小安全值。

统一消融实验使用相同 59 条种子、54 条查询、Top-5 和查询顺序，重复 3 次。openKylin 结果如下：

| 变体 | Recall@5 | P95 | P99 | 说明 |
|---|---:|---:|---:|---|
| 纯文本 FTS | 0.8426 | 0.314 ms | 0.499 ms | 速度最快，但召回不足 |
| 混合检索、无图谱追加 | 1.0000 | 1.514 ms | 1.897 ms | hash-vector 与候选补足恢复召回 |
| 完整系统、关闭结果缓存 | 1.0000 | 2.087 ms | 2.495 ms | 包含完整检索和图谱追加 |
| 完整系统、热结果缓存 | 1.0000 | 0.038 ms | 0.072 ms | 同进程重复查询 |
| Kylin SDK 可选增强 | 1.0000 | 279.641 ms | 1492.348 ms | 混合了首次端侧推理与后续向量缓存命中 |

上表保留的是旧版“查询时重复计算候选向量”证据。持久化向量检索 v2 已把候选向量写入 SQLite 缓存，查询阶段只执行一次查询向量推理，并使用相互独立的 lexical、hash、Kylin 排名做加权 RRF。最终 openKylin 三轮结果如下：

| 轮次 | Kylin 持久化 Recall@5 | Kylin P95 | Kylin P99 | 1k/6 worker hash P95 | 1k/6 worker hash P99 |
|---:|---:|---:|---:|---:|---:|
| 1 | 1.0000 | 242.484 ms | 253.625 ms | 181.494 ms | 301.228 ms |
| 2 | 1.0000 | 197.159 ms | 218.459 ms | 221.089 ms | 259.245 ms |
| 3 | 1.0000 | 199.581 ms | 206.711 ms | 196.862 ms | 251.799 ms |

三轮均满足 Recall@5 `=1.0000` 且 P95/P99 严格 `<500 ms`。并发负载显式固定为 hash 稳定路径，Kylin 质量延迟单独报告，避免把两种后端混为一个指标；原始逐轮数据、数据集 SHA256 和源修订见 `docs/evidence/retrieval_v2_openkylin.json`。旧证据仍用于说明无持久化设计的冷启动代价，当前产品策略已升级为“FTS/hash 稳定主路径 + Kylin 持久化 rerank + 延迟预算降级”。进程冷/热实验不宣称清空 Linux 内核页缓存。

通用证据包为 `docs/evidence/latest/`。真实 Agent 基础闭环证据包为 `docs/evidence/agent_latest/`，包含 OpenHands 运行时、本地模型、真实会话事件、三阶段上下文、systemd bridge、安全属性、交互状态、Web 快照、200 条专项 benchmark、审计链和 SHA-256 校验和。记忆价值证据包为 `docs/evidence/memory_value_latest/`，包含 16 组确定性配对指标、12 组真实会话逐案例结果、上下文快照、采集时 223 passed openKylin 测试快照、隔离审计链、manifest 和 SHA-256 清单；扩展证据包 `docs/evidence/real_agent_extension_r13_r20_latest/` 包含新增 R13-R20 8 组真实会话逐案例结果；holdout 留出证据包 `docs/evidence/real_agent_holdout_latest/` 包含 8 组盲测真实会话逐案例结果。`docs/evidence/openkylin_native_latest/` 已按最终源修订 `80963d0` 重采，包含 `654 passed, 1 skipped`、Kylin SDK、桌面插件、Polkit、systemd/cgroup、五包生命周期和检索 v2；三份真实 Agent 证据目录均包含 manifest 和 SHA-256 清单。

外部基准与资源对照说明：LongMemEval-V2 适配器用于降低“只在自建样例上验证”的质疑。当前实现遵循官方后端形态，把轨迹写入 MemGuardOS 并返回可追溯 context；由于答案生成层需要另配 reader/judge，测试报告只主张检索层适配，不把未运行答案层夸大为完整外部榜单成绩。严格资源对照使用同一 workload manifest 分别运行 `memory_disabled` 与 `memguardos_enabled`，报告成功率、延迟分位数、峰值 RSS 和平均 CPU，后续可由 `scripts/check_slo.py` 作为提交前门禁。
