# 02 用户手册

本文档说明普通用户如何使用 MemGuardOS 完成记忆写入、检索、RAG 上下文构建、精准遗忘、Web 控制台查看和基础诊断。更完整的企业级操作手册见 [交付文档/MemGuardOS中文操作手册.md](交付文档/MemGuardOS中文操作手册.md)。

## 1. 使用前准备

用户需要具备 Python 3.9 及以上环境，并在项目根目录完成安装：

```bash
python -m pip install -e ".[dev]"
```

安装完成后，可以使用模块方式运行，也可以在 editable install 生效后直接运行 `memctl`。如果在 openKylin `.deb` 安装后使用，命令入口为系统级 `memctl`。

## 2. 快速写入一条记忆

最简单的使用方式是写入一条自然语言偏好：

```bash
python -m memguard.cli.memctl ingest --text "以后回答 Linux 命令时先说明风险，再给可复制命令。"
```

系统会先检查文本质量，再识别敏感信息。如果文本中出现凭据、私钥或明确高风险路径，写入会被阻断或脱敏。通过校验后，系统会抽取记忆类型、标签、实体关系和解释信息，并写入 mmap 段文件与 SQLite 元数据索引。

## 3. 检索记忆

```bash
python -m memguard.cli.memctl search "Linux 命令风险提示"
```

检索结果通常包含记忆 ID、类型、来源、分数、文本摘要、标签和时间信息。用户可以根据结果判断系统是否找到了正确记忆。默认检索不依赖外部网络，适合离线环境和比赛复验。

## 4. 导入配置、行为和工具结果

配置导入用于把结构化配置转成记忆：

```bash
python -m memguard.cli.memctl ingest-config --file data/demo/user_config.json
```

shell 行为导入用于把用户命令历史转成可复用的行为记忆：

```bash
python -m memguard.cli.memctl ingest-history --file path/to/history.txt --limit 100
```

工具结果导入适合 OS Agent 自动调试场景：

```bash
python -m memguard.cli.memctl ingest-tool-result --file data/demo/tool_result_success.json
```

当工具结果中包含 `state_before`、`action`、`state_after` 和 `lesson` 等字段时，系统会将其建模为“状态—动作—结果”的程序性记忆。这类记忆可以帮助 Agent 在类似故障中复用修复路径。

## 5. 构建 RAG 上下文

```bash
python -m memguard.cli.memctl build-context "openKylin 服务内存限制" --top-k 5 --token-budget 1200
```

该命令会返回一个面向生成模型的上下文包。上下文包中包括已选记忆、脱敏文本、来源分布、记忆类型分布、层级分布、token 估算和选择轨迹。用户可以在交给 LLM 之前检查每条记忆为什么被选中，以及哪些内容因敏感或预算限制被过滤。

如果需要直接生成提示词，可以使用：

```bash
python -m memguard.cli.memctl build-prompt "openKylin 服务内存限制" --top-k 5 --token-budget 1200
```

## 6. 精准遗忘

精准遗忘建议先 dry-run：

```bash
python -m memguard.cli.memctl forget "忘掉 temporary project codename"
```

系统会返回候选记忆、匹配理由和风险提示。确认无误后再执行：

```bash
python -m memguard.cli.memctl forget "忘掉 temporary project codename" --yes --compact
```

执行后建议验证：

```bash
python -m memguard.cli.memctl verify-forget "temporary project codename"
```

`--compact` 会重写段文件，清理已删除记忆的明文载荷。该操作属于高风险维护操作，正式环境中应先备份数据目录。

## 7. Web 控制台

```bash
python -m memguard.cli.memctl web --host 127.0.0.1 --port 8765
```

浏览器打开 `http://127.0.0.1:8765` 后，可以查看系统状态、写入记忆、运行检索、构建上下文、执行精准遗忘、查看审计链和导出诊断信息。控制台默认绑定本机地址，不面向公网暴露。

## 8. 多会话隔离

```bash
python -m memguard.cli.memctl --namespace demo-a ingest --text "demo-a 只保存 systemd MemoryMax 方案。"
python -m memguard.cli.memctl --namespace demo-b search MemoryMax
python -m memguard.cli.memctl --namespace demo-a namespace-status
```

namespace 会让不同会话使用不同段文件、SQLite 数据库、审计链和敏感规则文件。它适合多项目、多 Agent 或演示隔离。

## 9. 常用诊断

```bash
python -m memguard.cli.memctl doctor
python -m memguard.cli.memctl verify-audit
python -m memguard.cli.memctl sdk-status --probe-embedding
python -m memguard.cli.memctl memory-policy
```

`doctor` 用于查看系统环境、存储、OS 机制和 SDK 状态。`verify-audit` 用于检查审计哈希链是否连续。`sdk-status` 用于检查 Kylin embedding/vector SDK 是否可用。`memory-policy` 用于查看 working、session、long_term 分层状态。
