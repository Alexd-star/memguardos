# MemGuardOS 用户使用指南

## 这是什么

MemGuardOS 是面向 openKylin 本机 Agent 的记忆安全服务。它会把用户与 Agent 的交互、工具执行结果和用户主动选择的文件，整理成可检索的记忆；在写入前检查敏感内容，在 Agent 使用前按任务阶段组织上下文，在用户提出遗忘请求后清理受管记录并返回逐项验证结果。

普通用户最常用三条入口：UKUI 控制中心的“日常使用”、系统托盘菜单和 Peony 文件管理器右键菜单。管理员可以使用本地 Web 控制台和 UKUI 的“管理员/系统维护”页。

在 UKUI 的“日常使用”页，除了打开本地控制台和文件管理器，还可以直接打开“Agent 工作台”或运行“体验流程”。体验流程使用本地可复现事件，不需要模型服务，适合第一次了解产品；页面会明确标记这是回放结果，不会把它冒充成真实模型运行。

## 推荐使用顺序

1. 打开“MemGuardOS 记忆安全中心”，确认服务运行和操作记录完整性。
2. 在 Peony 中右键选择文件，先看检查结果，再勾选允许保存的文件。敏感文件不会因为勾选而绕过保护。
3. 在 Web 控制台的“Agent 工作台”输入任务。需要可复现核验时选择“本地回放”；需要只读查看时选择“只读预览”；真实模型运行必须选择真实 Agent 入口并确认模型服务可用。
4. 查看“偏好生效”页，区分“已观察到并通过”和“暂无实际行为证据”。上下文注入本身不等于 Agent 已经遵循。
5. 不再需要某条记忆时，先在“遗忘验证”页预览候选，再由有权限的用户确认。确认后查看主记录、索引、段文件、上下文和操作记录的验证结果。

## 用户能看到什么

每次保存会显示“系统学到了什么、为什么保存、会在哪些场景使用”；敏感信息会显示“已保护，未进入长期记忆和检索上下文”；遗忘会显示逐项验证和外部残留边界。OpenHands 原始日志、模型提供商日志、shell history、虚拟机快照和备份不属于 MemGuardOS 受管范围，不能把逻辑遗忘描述成介质级销毁。

## CLI

普通用户入口：

```bash
python -m memguard.cli.memguard status
python -m memguard.cli.memguard demo
python -m memguard.cli.memguard shell
python -m memguard.cli.memguard --json demo
```

交互式入口支持 `/help`、`/status`、`/memory`、`/preferences`、`/search 关键词`、`/context 任务`、`/forget 请求`、`/audit`、`/evidence`、`/demo`、`/model`、`/workspace` 和 `/exit`。`--json` 仅供自动化和审计脚本使用，普通界面不要求用户阅读 JSON。

## 真实性说明

“本地回放”是实际写入 MemGuardOS 的标准化事件回放，用于复验记忆链；“只读预览”不写入事件；“真实 OpenHands”才代表模型驱动运行。三种模式在界面和输出中明确标注，不能混用证据口径。

系统托盘会根据重要事件提供克制提醒。敏感内容保护、高风险工具拦截、遗忘结果、服务异常和实际 Agent 偏好更新可以弹出通知；普通检索、缓存命中和本机智能检索状态变化只进入“通知中心”，不会持续打断工作。托盘菜单中的“最近学到的记忆”“最近生效的偏好”“最近 Agent 任务”和“最近遗忘验证”会直接打开对应页面。
