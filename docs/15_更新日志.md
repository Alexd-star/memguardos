# 15 更新日志

本文档是面向中文读者的版本说明入口。完整工程更新记录见根目录 [../CHANGELOG.md](../CHANGELOG.md)。这里按能力域说明当前版本的主要成果，不记录零散过程。

## 1. 2026-06-20 更新

本次更新围绕小参数本地模型在工具调用格式、偏好执行和最终回答遵循方面的波动，补充了偏好执行 Hook、一次有界合规修复、严格只读结构化工具意图恢复、失败命令规范化恢复和程序性记忆结果兜底。所有恢复动作均保留来源字段，模型原始尝试、策略拒绝和最终执行不会混为一谈。

偏好冲突选择增加 Agent 事件时间与 SQLite 插入序号作为稳定排序依据，解决数据库时间戳相同时旧偏好偶发覆盖新版偏好的问题。证据采集同时支持不含 Git 元数据的 openKylin 同步目录，并提供独立的 SHA256 与 manifest 刷新工具。

当前本地测试为 `292 passed, 1 skipped`，最新同 HEAD openKylin 为 `290 passed`。16 组确定性配对实验全部通过；原 12 组真实 OpenHands 会话与新增 R13-R20 扩展会话合计 28 组均已归档（含 8 组 holdout 留出盲测），记忆系统层与 Agent 行为层均为 `28/28`。

## 2. 当前版本

当前项目版本为 `0.1.0`，定位是面向研究生操作系统开源创新大赛赛题 3 的可运行原型和竞赛交付版本。版本号来自 `pyproject.toml`。

## 3. 主要能力

当前版本已经形成完整主链路：多源接入、质量治理、敏感检测、偏好/知识/程序性记忆抽取、mmap+SQLite 轻量存储、FTS/hash/graph 混合检索、RAG 上下文解释、精准遗忘、compact、审计哈希链、namespace 隔离、systemd/cgroup/auditd/journald/BPF LSM/UKUI/Peony 集成、Unix socket API、Web 控制台、openKylin 证据采集和 `.deb` 安装验证。

新增 `PROJECT_INDEX.md` 和 `docs/01_项目简介.md` 到 `docs/17_项目交付说明.md`，用于把项目资料按简介、用户、操作、开发、架构、代码、模块、算法、接口、数据、配置、部署、测试、FAQ、更新、历史和交付维度重新组织。原有正式文档不被覆盖，继续作为评审和证据主材料。

## 4. 指标口径提醒

文档中的 OS 机制证据以 `docs/evidence/latest/` 为准，真实 Agent 证据以 `docs/evidence/agent_latest/` 为准，优化后的并发和消融指标以 `docs/evidence/performance_latest/` 及 [测试报告.md](测试报告.md) 为准。本地测试数量、openKylin 测试数量、单查询、并发检索、Kylin SDK 冷启动和 Agent batch P95 必须区分环境与测量口径。

## 5. 2026-06-19 性能增强

当前版本已将检索候选生成改为按预算逐级补足，并让批量检索工作线程复用服务和 SQLite 连接。openKylin 独立三轮 6 worker 并发试验最差 P95 为 54.381 ms，完整 10k 评测进程内并发 P95 为 139.264 ms；10k 主负载 P95 为 10.105 ms。新增统一消融实验，证明纯文本检索 Recall@5 为 0.8426，混合检索和完整系统均为 1.0000。

后续版本可继续加强真实业务日志样例、Web 控制台交互体验、UKUI/Peony 可用闭环、更多端侧 embedding 后端、权限模型和 API 鉴权。任何新增能力都应同步更新测试、证据和中文文档。
