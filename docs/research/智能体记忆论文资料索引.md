## 2. 本地资料文件

资料已保存在 `docs/research/sources/`。每篇论文包含 Hugging Face Markdown、Hugging Face 正文 Markdown、arXiv 摘要 HTML、arXiv PDF、PDF 提取文本。

| 文件类型 | 命名规则 | 用途 |
|---|---|---|
| Hugging Face 页面 Markdown | `hf_<arxiv_id>.md` | 页面标题、摘要、讨论与 Hugging Face 展示内容 |
| Hugging Face 正文 Markdown | `hf_content_<arxiv_id>.md` | Hugging Face paper chat 使用的正文 Markdown |
| arXiv 摘要 HTML | `arxiv_abs_<arxiv_id>.html` | 标题、作者、提交时间、摘要交叉校验 |
| arXiv PDF | `arxiv_<arxiv_id>.pdf` | 原始论文 PDF |
| PDF 提取文本 | `arxiv_<arxiv_id>.txt` | 本地检索、引用核查、全文快速阅读 |
| 抓取记录 | `fetch_results.json` | 每个 URL 抓取是否成功、文件大小、Content-Type |
| 元数据 | `paper_metadata.json` | 标题、作者、提交日期、摘要 |
| 粗摘要 | `paper_summaries_raw.json` | 自动抽取的摘要与章节标题，供检索参考 |

## 3. 快速检索建议

后续查找论文观点时，优先使用 `rg` 在 `docs/research/sources/*.txt` 中检索，避免重新打开大 PDF。

常用检索词：

```powershell
rg -n "formation|evolution|retrieval|forgetting|consolidation|trustworthiness" docs/research/sources/arxiv_2512.13564.txt
rg -n "PRAXIS|procedural|state|action|result|reliability|efficiency" docs/research/sources/arxiv_2511.22074.txt
rg -n "hierarchical|knowledge graph|multimodal|forgetting|bounded" docs/research/sources/arxiv_2512.03627.txt
rg -n "page-store|Memorizer|Researcher|just-in|JIT|complete history" docs/research/sources/arxiv_2511.18423.txt
rg -n "persona|event|working memory|episodic|token|latency" docs/research/sources/arxiv_2511.13593.txt
rg -n "conversational|long-term user|sensory|working|conflict|privacy" docs/research/sources/arxiv_2512.01710.txt
rg -n "CogniGraph|hierarchical|temporal|entity|relation|efficiency" docs/research/sources/arxiv_2511.01448.txt
```

## 4. 阅读优先级

如果时间有限，建议按以下顺序阅读：

1. `2512.13564`：建立智能体记忆的总框架，尤其是 forms、functions、dynamics。
2. `2511.18423`：理解“完整历史页库 + 运行时研究式上下文生成”的高保真路线。
3. `2511.22074`：补足 MemGuardOS 目前较弱的程序性记忆、工具轨迹与状态-动作-结果经验学习。
4. `2511.01448`：对照 MemGuardOS 的图谱和时间有效性，改进层次化检索与时间重排。
5. `2511.13593` 与 `2512.01710`：完善偏好、用户画像、事件记忆、多层记忆协调与 token/延迟权衡。
6. `2512.03627`：作为多模态和长期方向参考，不建议在当前赛题冲刺阶段强行引入重型多模态依赖。
7. `2510.16720`：作为范式判断材料，用于说明 MemGuardOS 为什么采用端侧系统组件路线，而不是完全模型内生记忆路线。
