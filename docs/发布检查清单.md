# 发布检查清单

本文用于每次生成最终提交包或 GitHub release 前核对。

## 1. 本地质量门禁

- [ ] `python -m ruff check memguard tests scripts`
- [ ] `python -m pytest -q`
- [ ] `python scripts/check_docs_links.py`
- [ ] `python -m memguard.eval.run_eval --latency-size 1000 --latency-queries 120`

## 2. openKylin 证据

- [ ] `python -m pytest -q`
- [ ] `python -m memguard.eval.run_eval --latency-size 1000 --latency-queries 120`
- [ ] `bash scripts/openkylin_verify.sh`
- [ ] `bash scripts/collect_openkylin_evidence.sh`
- [ ] 如更新 10k 指标：复跑 `--latency-size 10000 --latency-queries 150`

## 3. 文档口径

- [ ] `docs/测试报告.md` 已更新最新测试和评测数字。
- [ ] `docs/赛题要求逐句符合性核查.md` 不夸大未验证能力。
- [ ] `docs/评委证据包索引.md` 指向最新证据包。
- [ ] `docs/最终提交检查清单.md` 勾选状态真实。
- [ ] `docs/提交材料边界说明.md` 区分作品主体和工程化支撑。

## 4. 安全与隐私

- [ ] 没有真实 API key、token、密码、私钥。
- [ ] 没有未脱敏 PII。
- [ ] 没有提交 `.sqlite3`、`.segment`、`.venv/`、缓存目录。
- [ ] evidence 中只包含可公开或可提交的脱敏证据。

## 5. 打包和 Git

- [ ] `python scripts/package_submission.py`
- [ ] 优先提交 `memguardos_competition_submission_*.zip`。
- [ ] 如需 GitHub release 或备份，再附 `memguardos_full_repository_*.zip`。
- [ ] 检查 manifest 中没有缓存、虚拟环境、`*.egg-info/` 或 dist 套包，并确认角色分类没有异常的“其他”核心文件。
- [ ] `git status -sb` 干净或只包含预期变更。
- [ ] `git tag` 如需发布新版本。
- [ ] `git push` 和 `git push --tags`。

## 6. 演示视频

- [ ] 视频时长 3-5 分钟。
- [ ] 视频在 openKylin 虚拟机中录制。
- [ ] 展示多源接入、检索、敏感阻断、精准遗忘、OS 机制、评测结果。
- [ ] 视频中不展示真实 token、密码、私钥或个人隐私。
