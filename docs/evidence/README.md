# 精选验证证据

本目录保存可直接复核、体积受控的代表性原始结果。完整原始证据包在正式 Release 中以独立附件发布，避免把大量历史日志和逐案例中间文件长期堆积在源代码树中。

| 目录 | 内容 | 能证明什么 |
|---|---|---|
| `openkylin/` | 系统版本、服务、cgroup、Kylin SDK、桌面插件、五包生命周期和测试摘要 | 指定源修订在 openKylin 上的原生安装与运行状态 |
| `openkylin/action_feedback_evidence_20261007.json` | 行动预检、实际遵循、偏离、幂等重试和旧收据拒绝 | 证明记忆影响 Agent 行动后的结果可被区分、回写和治理 |
| `openkylin/memory_budget_evidence_20261007.json` | 价值、风险、估算字节成本、受保护偏好和可逆降级 | 证明长期记忆预算计划来自当前代码，并在确认后追加 session 版本 |
| `performance_latest/` | 10k 负载、并发、消融和检索 v2 原始 JSON/报告 | 指定协议下的召回和延迟，不代表所有硬件 |
| `agent/` | 200 条交互专项、确定性记忆价值实验和真实 OpenHands 汇总 | 事件链、跨会话复用、真实运行与留出场景结果 |
| `portability/` | Ubuntu CI 与 Debian 容器摘要 | 非 openKylin Linux 环境的基本可移植性 |
| `finals_20261006/` | 来源绑定的流程复用、撤回、安装态与遗忘专项 | 当前实现的实际条件验证与派生治理，不代替自主 Agent 任务效果 |

## 完整性规则

最终发布前使用 `scripts/write_evidence_manifest.py` 或对应采集脚本生成 SHA-256 清单，并检查证据中的源修订与发布标签一致。历史证据只用于说明演进过程，不得覆盖或冒充最终证据。

## 解释边界

- `passed` 证明已执行测试通过，不证明未覆盖路径绝对无缺陷。
- 自建 benchmark 的 1.0000 证明该数据集上的确定性结果，不等同于开放世界泛化率。
- 真实 Agent 汇总证明 OpenHands 会话确实运行并经过记忆链路，不应与确定性配对实验的因果增益混为一个指标。
- 精准遗忘证据仅覆盖 MemGuardOS 管理的数据面，不包含外部日志、备份和介质级残留。
