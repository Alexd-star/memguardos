# MemGuardOS 安全与精准遗忘设计

## 1. 安全目标

MemGuardOS 在三个阶段保护智能体记忆：

1. **入库前**：识别并阻断敏感数据。
2. **检索时**：不返回已删除或高风险记忆。
3. **遗忘后**：确保被遗忘明文不能从元数据、索引或段文件中恢复。

设计上同时使用应用层规则和 OS 上下文信号。

## 2. 威胁模型

| 威胁 | 示例 | 缓解措施 |
|---|---|---|
| 凭据被记忆 | API key、token、private key 进入记忆 | 高风险检测直接阻断 |
| PII 泄漏 | 邮箱、手机号、身份证进入记忆 | 脱敏后存储 |
| 敏感文件被智能体读取 | `.ssh/id_rsa`、`.env`、`/etc/shadow` | OS 路径信号提高风险等级 |
| 遗忘后仍可检索 | 内容残留在索引、缓存、段文件 | tombstone、元数据清除、图谱清除、compact、探针验证 |
| 审计被篡改 | 操作日志被修改 | 哈希链验证 |
| 过度遗忘 | 宽泛请求误删无关知识 | dry-run 候选和 keep-success 指标 |

## 3. 敏感检测

实现文件：

- `memguard/sensitivity/detector.py`
- `memguard/sensitivity/custom_patterns.py`

检测来源：

1. 内置模式：邮箱、手机号、身份证、中文姓名、中文地址、银行卡号、API key、AWS Access Key ID、token/password/secret 赋值、private key。
2. 自定义模式：通过 `memctl patterns add` 添加。
3. OS 来源信号：`.env`、`.ssh`、`authorized_keys`、`id_rsa`、`/etc/shadow`、`/etc/ssh`。

策略：

| 等级 | 动作 |
|---|---|
| high | 阻断存储，写入审计 |
| medium | 脱敏后存储 |
| low | 脱敏后存储 |
| none | 正常存储 |

## 4. OS 级敏感访问

实现文件：

- `memguard/os_guard/events.py`
- `memguard/os_guard/auditd.py`
- `scripts/install_auditd_rules.sh`
- `scripts/auditd_to_memguard.sh`

流程：

```text
auditd/fanotify/eBPF 风格事件
  -> ingest-os-event / ingest-auditd
  -> 解析 path/process/action
  -> 路径进入敏感检测器
  -> 高风险 OS 来源被阻断
  -> 审计事件记录
```

便携 smoke test：

```bash
python -m memguard.cli.memctl ingest-os-event --json '{"event_type":"fanotify_open","path":"/home/u/.ssh/id_rsa","process":"cat","action":"read"}'
```

openKylin auditd 验证：

```bash
python -m memguard.cli.memctl auditd-rules --format auditctl
sudo bash scripts/install_auditd_rules.sh "$(pwd)"
sudo ausearch -k memguard_sensitive -i
```

## 5. 精准遗忘

实现文件：

- `memguard/forgetting/planner.py`
- `MemGuardService.forget()`
- `MemGuardService.compact()`
- `MemGuardService.verify_forget_probe()`

流程：

```text
请求："忘掉 temporary project codename"
  -> 关键词/实体候选选择
  -> dry-run 预览
  -> 确认后 tombstone
  -> SQLite 内容清除
  -> FTS 删除
  -> 图谱边删除
  -> compact 段文件
  -> 明文探针验证
```

关键行为：

- dry-run 不删除任何内容。
- 确认遗忘会清除元数据明文和搜索索引。
- `compact()` 从追加式段文件历史中移除旧明文。
- `verify-forget --probe` 检查明文探针是否仍存在于段文件。

## 6. 审计哈希链

实现文件：

- `SQLiteMetaStore.add_audit()`
- `SQLiteMetaStore.verify_audit_chain()`

每条审计事件包含：

```text
prev_hash
event_hash = SHA256(prev_hash | event_type | memory_id | detail | created_at)
```

验证命令：

```bash
python -m memguard.cli.memctl verify-audit
```

期望结果：

```json
{
  "ok": true,
  "checked": 12,
  "head_hash": "..."
}
```

## 7. 安全评测

当前评测包括：

- 敏感阻断 F1；
- 脱敏 F1；
- 敏感标签 F1；
- 遗忘候选精确率；
- 遗忘候选召回率；
- 应保留记忆成功率；
- 审计哈希链测试；
- compact 不可逆清除测试；
- OS 敏感路径测试。

为了降低误报，中文姓名和地址检测采用上下文触发策略，例如“姓名是张三”“收货地址是北京市...”会脱敏；普通中文短语不会被当作姓名处理。

运行：

```bash
python -m pytest -q
python -m memguard.eval.run_eval --latency-size 1000 --latency-queries 120 --output docs/eval_result.json --markdown docs/eval_report.md
```
