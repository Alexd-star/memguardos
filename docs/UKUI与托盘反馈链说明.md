# UKUI 与托盘反馈链说明

## UKUI 控制中心

日常使用页不再只显示服务状态，还会读取 `memctl feedback-home`，展示最近学到的内容、稳定偏好、敏感保护和最近遗忘。管理员页保留服务控制、本机智能检索、授权和资源状态；系统维护页保留日志、报告、原生证据和验收入口。耗时操作有取消、超时和结果位置提示。

## 托盘

托盘提供记忆安全中心、本机智能检索、操作记录、已保护内容、最近学到的记忆、最近生效偏好、最近 Agent 任务、最近遗忘验证和 Agent 工作台入口。托盘会轮询通知中心并按 `notification_id` 去重：敏感内容保护、高风险工具拦截、遗忘结果、操作记录异常、服务异常和实际 Agent 偏好更新可以弹出系统通知；普通记忆新增、本机智能检索降级和缓存变化只进入通知中心。用户可以暂停通知一小时。托盘不会把内部 JSON 直接展示给普通用户，菜单中的页面入口使用 Web 控制台 hash 直接定位到目标页面。

UKUI 日常使用页提供“打开 Agent 工作台”和“运行体验流程”。前者打开本地控制台的 Agent 页面，后者执行 `memguard demo` 的本地回放模式，结果进入系统维护的维护结果区；两者都不会把无模型的回放描述成真实 OpenHands 会话。

## Peony

右键文件后先生成签名扫描清单。弹窗按“可导入、已保护、只记录、文件不存在”等用户语言解释建议动作。导入后显示新增记忆数量、适用场景和“测试生效”；撤销导入直接把本批 `memory_id` 交给遗忘服务，并显示统一遗忘验证报告。

## 构建和安装

在 openKylin 上使用 `scripts/build_ukui_plugins.sh` 构建，再安装 Peony、UKUI 控制中心和托盘资源。Windows 开发机可以执行契约测试，但不能替代 openKylin 的真实桌面验证。最终证据必须在目标 VM 同一 Git HEAD 上重新采集。
