## 当前剩余风险

| 风险 | 影响 | 应对 |
|---|---|---|
| Kylin 文本向量化 SDK 推理超时 | 不能宣称主检索完全由 SDK embedding 驱动 | 保留 SDK 探测和 fallback，答辩中诚实说明，并用向量数据库 SDK 探针补强 openKylin 适配证据 |
| 可选 LLM adapter 与 bpftrace 探针不属于默认主路径 | 避免外部 API、root 权限或 bpftrace 环境影响复现 | 默认使用 dry-run 和 auditd 主路径，答辩中按“可选增强”表述 |
| 文档历史版本中仍有英文 | 影响评委阅读体验 | 提交前执行中文化审查，核心提交文档优先中文 |
| demo 视频未录制 | 提交材料不完整 | 功能冻结后在 openKylin 录制，不提前录制 |
| fanotify/eBPF 未实现 | 少一个加分型 OS 机制 | auditd、mmap、systemd/cgroup、journald 已满足核心要求；fanotify/eBPF 作为时间允许的增强项 |
