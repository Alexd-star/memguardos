# 图谱记忆设计

MemGuardOS 包含轻量级图谱记忆层，用于结构化知识记忆和关联检索。

## 目标

图谱记忆层对应赛题中的以下要求：

- 知识记忆结构化；
- 关联检索；
- 跨场景记忆复用；
- 可解释检索；
- 冲突分析辅助。

## 实现

核心文件：

- `memguard/extraction/entity.py`
- `memguard/store/sqlite_meta.py`
- `memguard/service.py`

SQLite 表：

- `entity(entity, updated_at)`
- `memory_entity(memory_id, entity)`
- `relation(memory_id, source, relation, target)`

当前抽取器采用轻量规则方式，优先识别 OS/智能体记忆领域实体，例如：

- `openKylin`
- `Linux`
- `systemd`
- `cgroup`
- `journald`
- `auditd`
- `fanotify`
- `eBPF`
- `mmap`
- `COW`
- `precise_forgetting`
- `sensitive_data`
- `agent_memory`

同时会保留文本中类似标识符的技术 token，方便检索命中命令、模块名和配置项。

## 命令

```bash
python -m memguard.cli.memctl ingest --text "systemd MemoryMax 可以限制 Linux 服务内存。"
python -m memguard.cli.memctl graph-search systemd
python -m memguard.cli.memctl related <memory_id>
```

## 与普通检索的融合

普通检索使用：

1. FTS 候选预筛选；
2. 词法 + 轻量向量式混合重排；
3. 图谱实体扩展；
4. 无命中时 LIKE/FTS 回退。

图谱命中会标记：

```json
{
  "match_source": "graph"
}
```
