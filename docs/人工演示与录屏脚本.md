# 人工演示与录屏脚本

## 录制目标

录制过程不展示调试信息和大段 JSON，重点让观众看到“记忆产生、偏好生效、风险阻断、精准遗忘、验证留证”五个结果。原始 JSON 可在管理员高级信息区或导出文件中补充，不作为普通用户主画面。

## 推荐脚本

1. 打开 UKUI 控制中心，展示“日常使用”页的服务、最近记忆变化和常用入口。
2. 点击“查看最近变化”，说明这里不是静态演示文字，而是从当前 namespace 的真实 MemGuardOS 记录读取。
3. 打开本地控制台，进入“Agent 工作台”，输入“查找 MemGuardService 的定义”，运行“本地回放（可复现）”。
4. 依次展示注入上下文、工具命令、工具结果和“code_search_tool = rg 已观察到并通过”。说明回放不冒充真实模型能力。
5. 在“记忆写入”输入一条含凭据格式的文本，展示“已保护敏感内容，未进入长期记忆或检索上下文”。
6. 进入“遗忘验证”，先点“预览影响”，再点确认，展示主记录、索引、段文件、上下文和审计链的状态。
7. 打开通知中心，展示重要事件；说明普通检索和 SDK 降级不会频繁弹窗。
8. 最后进入 UKUI“系统维护”，导出报告并展示保存位置和当前版本证据。

## 真实 Agent 录制

真实 OpenHands 录制必须在模型服务、工作区和网络/API 配置均已确认的环境中执行。录屏中要看到真实运行模式、工具调用和原始结果；如果模型不可用，改用本地回放并明确说“这是事件链复核，不是模型独立能力证明”，不能用回放结果替代真实 Agent 证据。
