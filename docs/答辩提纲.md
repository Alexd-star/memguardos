# MemGuardOS 答辩提纲

## 第 1 页：标题

MemGuardOS：面向 Linux 的智能体记忆提取与精准遗忘机制

副标题：

面向 openKylin OS Agent 的安全记忆基础设施。

## 第 2 页：问题背景

Linux 智能体会不断积累：

- 用户偏好；
- 命令工作流；
- 工具执行结果；
- 系统事件；
- 潜在敏感凭据。

普通 RAG 记忆库通常缺少：

- OS 机制；
- 版本回滚；
- 精准遗忘；
- 审计；
- 敏感访问拦截；
- 资源控制。

## 第 3 页：设计目标

MemGuardOS 提供：

- 多源记忆提取；
- working/session/long_term 记忆层级；
- 结构化知识记忆；
- 混合检索和图谱检索；
- 带 OS 上下文的敏感检测；
- 自然语言精准遗忘；
- 可审计、可验证、不可逆的删除。

## 第 4 页：总体架构

使用 `概要设计说明书.md` 中的 Mermaid 架构图。

强调：

- 接入层；
- 敏感检测器；
- mmap 段文件；
- SQLite/FTS/图谱；
- 遗忘规划器；
- 审计哈希链；
- journald/auditd/cgroup 集成。

## 第 5 页：OS 机制

已实现或已验证：

- mmap 段文件读取路径；
- 追加式/COW 风格版本存储；
- systemd/cgroup 服务资源限制；
- journald 桥接；
- auditd 敏感路径规则；
- OS 事件接入层。

## 第 6 页：记忆模型

记忆卡片包含：

- 类型：`preference`、`knowledge`、`sensitive_policy`；
- 子类型：输出风格、工具偏好、安全策略、工作流、案例、模板等；
- 层级：`working`、`session`、`long_term`；
- 来源和证据；
- 敏感标签；
- 版本信息；
- 图谱实体/关系；
- 审计哈希。

## 第 7 页：精准遗忘

演示流程：

```text
dry-run -> confirm -> tombstone -> index purge -> compact -> probe verification
```

关键表达：

> MemGuardOS 不只是把已遗忘记忆从搜索结果中隐藏，而是在 compact 后验证旧明文已从段文件中移除。

## 第 8 页：安全治理

敏感检测融合：

- 内置 PII/凭据模式；
- 用户自定义模式；
- OS 来源路径信号；
- auditd 真实日志；
- 审计哈希链。

展示 `.ssh/id_rsa` 或 `/etc/shadow` 事件被阻断。

## 第 9 页：图谱记忆

展示：

- `graph-search systemd`
- `related <memory_id>`
- 实体和关系

说明：

图谱记忆支持结构化知识记忆、关联检索和可解释命中。
