# MemGuardOS 答辩提纲

## 第 1 页：标题

MemGuardOS：面向 Linux 的智能体记忆提取与精准遗忘机制

副标题：

面向 openKylin OS Agent 的安全记忆基础设施。

## 第 2 页：问题背景

Linux 智能体会不断积累：

- 用户偏好；
- 命令工作流；
- 工具执行结果；
- 系统事件；
- 潜在敏感凭据。

普通 RAG 记忆库通常缺少：

- OS 机制；
- 版本回滚；
- 精准遗忘；
- 审计；
- 敏感访问拦截；
- 资源控制。

## 第 3 页：设计目标

MemGuardOS 提供：

- 多源记忆提取；
- 可解释混合语义抽取，可选接本地 NER/LLM 增强；
- working/session/long_term 记忆层级；
- 结构化知识记忆；
- 混合检索和图谱检索；
- 面向任务规划、工具调用、结果生成的 Agent 批量检索；
- 记忆策略报告、冷热分层和淘汰建议；
- 带 OS 上下文的敏感检测；
- 自然语言精准遗忘；
- 可审计、可验证、不可逆的删除。
- 本地 Web 控制台，便于评审现场查看状态、写入、抽取解释、检索、遗忘和审计。

## 第 4 页：总体架构

使用 `概要设计说明书.md` 中的 Mermaid 架构图。

强调：

- 接入层；
- 敏感检测器；
- mmap 段文件；
- SQLite/FTS/图谱；
- 遗忘规划器；
- 审计哈希链；
- journald/auditd/cgroup 集成。

## 第 5 页：OS 机制

已实现或已验证：

- mmap 段文件读取路径；
- 追加式/COW 风格版本存储；
- namespace 多会话隔离；
- systemd/cgroup 服务资源限制；
- systemd 模板服务独立 cgroup；
- 索引缓存、冷热分层、批量并发检索；
- journald 桥接；
- auditd 敏感路径规则；
- OS 事件接入层；
- BPF LSM `file_open` 强制拦截安全测试文件；
- BPF LSM JSON denylist 策略生成；
- Peony 右键菜单和 UKUI 控制中心入口均已可见验证。

## 第 6 页：记忆模型

记忆卡片包含：

- 类型：`preference`、`knowledge`、`sensitive_policy`；
- 子类型：输出风格、工具偏好、安全策略、工作流、案例、模板等；
- 层级：`working`、`session`、`long_term`；
- 来源和证据；
- 敏感标签；
- 版本信息；
- 图谱实体/关系；
- 审计哈希。
- 抽取信号：`method`、`signals`、`confidence`，用于回答“为什么判定为偏好/知识/安全策略”。

## 第 7 页：精准遗忘

演示流程：

```text
dry-run -> confirm -> tombstone -> index purge -> compact -> probe verification
```

关键表达：

> MemGuardOS 不只是把已遗忘记忆从搜索结果中隐藏，而是在 compact 后验证旧明文已从段文件中移除。

## 第 8 页：安全治理

敏感检测融合：

- 内置 PII/凭据模式；
- 用户自定义模式；
- OS 来源路径信号；
- auditd 真实日志；
- 审计哈希链。

展示 `.ssh/id_rsa` 或 `/etc/shadow` 事件被阻断。

## 第 9 页：图谱记忆

展示：

- `graph-search systemd`
- `related <memory_id>`
- 实体和关系

说明：

图谱记忆支持结构化知识记忆、关联检索和可解释命中。

## 第 10 页：openKylin 适配

展示：

- openKylin 2.0 SP2 VM 验证；
- Kylin embedding SDK 检测到 768 维端侧文本模型；
- Kylin embedding SDK Python/C++ 探针返回 768 维向量；
- `MEMGUARD_EMBEDDING_BACKEND=auto` 实际检索返回 `vector_backend: "kylin_sdk"`；
- Kylin vector SDK C++ 探针搜索成功；
- namespace 模板服务 `memguardd@demo-a/demo-b` 独立 cgroup；
- systemd/cgroup 资源限制；
- auditd 真实敏感日志接入；
- BPF LSM 对 `/tmp/memguardos_lsm_secret` 强制拒绝；
- BPF LSM denylist 可由 JSON 生成并审查；
- Peony 右键菜单插件已在 openKylin 桌面菜单中可见；UKUI 控制中心入口“MemGuardOS 记忆安全”已在设置界面中可见，当前源码提供运行环境检查、审计链校验、端侧向量能力检查、诊断报告和本地控制台入口。

强调：

默认检索链路采用轻量 FTS/hash/graph，Kylin embedding 作为 openKylin 原生可选增强后端。

BPF LSM 默认只拦安全测试文件，不拦 `/etc/shadow`、SSH、sudo 或 PAM 相关路径；UKUI/Peony 表述为“Peony 右键菜单和 UKUI 控制中心入口均已可见验证”，但 bind mount 是演示安装方式。

## 第 13 页：总结与边界

已完成：

- 核心功能闭环；
- openKylin 验证；
- OS 级机制；
- BPF LSM 和 UKUI 原生插件增强证据；
- BPF LSM 策略生成、本地 Web 控制台和可解释抽取证据；
- SDK 证据；
- Agent 批量检索、记忆策略报告和 RAG token 预算评测；
- 指标评测；
- 中文提交文档主体。

边界说明：

- BPF LSM 默认只拦安全测试文件，不影响登录、SSH、sudo 或 PAM 链路；
- Peony 右键菜单和 UKUI 控制中心入口均已在 openKylin 桌面可见验证；
- Web 控制台是本地评审/演示入口，不是公网 SaaS 多租户系统；
- 默认抽取器为端侧可解释基线，可选语义增强器需要显式配置；
- 默认检索链路不依赖外部 LLM API 或 GPU；
- Kylin embedding 是可选重排增强，默认 FTS/hash/graph 路径保证跨环境复现；
- 演示视频作为正式提交独立附件，脚本已提供。
