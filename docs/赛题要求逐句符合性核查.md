## 1. 总体结论

当前 MemGuardOS 已覆盖赛题 3 的核心任务：接入现有 OpenHands Agent，自动采集用户与 Agent 的消息、反馈、工具调用和工具结果；提取显式偏好、隐式习惯、纠正信息和程序性知识；在任务规划、工具选择和结果生成阶段构建上下文；完成跨会话复用和范围化精准遗忘。同时保留版本管理、混合检索、短中长期记忆、敏感治理、mmap 存储、namespace、systemd/cgroup、journald、auditd、BPF LSM、UKUI、openKylin 复验和量化评测。

根据赛题老师最新答复，“用户操作习惯”重点指用户与 Agent 的交互习惯。项目已据此把 OpenHands 交互事件升级为主数据源，shell history、配置、OS 事件和 auditd 仅作为补充来源。完整门禁与证据包已经复跑；当前剩余的独立人工交付项是最终 3-5 分钟演示视频及平台上传。

## 7. 答辩时应避免的过度宣称

1. 不说“默认主检索完全依赖 Kylin embedding SDK”。准确说法：已检测到 Kylin 文本向量化 SDK 和 768 维端侧模型，Python/C++ 探针均可返回 768 维向量；`MEMGUARD_EMBEDDING_BACKEND=auto` 实际检索可返回 `vector_backend: "kylin_sdk"`；系统采用可选 Kylin 增强加稳定 fallback，另有 Kylin 向量数据库 SDK C++ 搜索探针成功。
2. BPF LSM 可以说“openKylin 上已编译、attach 并对安全测试文件强制拒绝”。不要说默认拦截 `/etc/shadow`，因为默认安全演示模式不会触碰登录链路。
3. 可以说“已完成 OpenHands 用户交互习惯自动捕捉、跨会话复用和范围化遗忘，28 组真实会话中记忆系统层与 Agent 行为层均为 28/28”。必须同时说明偏好 Hook、合规修复和只读恢复属于适配层能力，不能把完整系统通过率表述为 1.7B 模型单独的通用成功率，也不能说“捕获所有桌面行为”。
4. 不说“默认链路依赖外部 LLM”。准确说法：当前完成检索、过滤、证据组织、RAG 上下文包、provider-neutral prompt 渲染和可选 LLM adapter；默认 dry-run 不联网，显式配置后可接本地命令或兼容远程端点。
5. 不说“遗忘后物理磁盘绝对不可法证恢复”。准确说法：系统层面通过 tombstone、索引/图谱清理和 compact 移除可访问明文，审计保留删除事实；底层磁盘法证恢复不属于当前用户态原型保证范围。

## 8. 推荐复验顺序

1. 如代码、文档或证据再次变化，复跑本地 pytest、ruff、benchmark 和 release preflight，确认文档和证据同步没有回归。
2. 录制 3-5 分钟 openKylin 演示视频，优先展示真实 OpenHands 事件、偏好证据、跨会话三阶段上下文、范围化精准遗忘，再展示 Kylin SDK、namespace/cgroup、auditd 和评测。
3. 视频录制前快速复跑 `bash scripts/openkylin_verify.sh`，确认 SDK、pytest、auditd 和审计链仍正常。
4. 如重新生成提交包，运行 `scripts/package_submission.py`、`scripts/inspect_submission_package.py` 和 `scripts/smoke_submission_archive.py`，确认正式源码压缩包边界清晰且可独立运行核心 smoke。
