# MemGuardOS 最终缺口补齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 除双人独立标注外，完成严格资源对照、LongMemEval-V2 外部验证、记忆污染治理、企业安全交付和同 HEAD openKylin 证据闭环。

**Architecture:** 在现有 `MemGuardService`、SQLite 元数据、CLI/Web 和评测模块上增加相互独立的治理与评测边界。外部数据不进入生产依赖，资源采样由独立父进程完成，治理状态由 SQLite 持久化并在所有检索入口统一过滤。

**Tech Stack:** Python 3.10+ 标准库、SQLite/FTS5、pytest、OpenHands、LongMemEval-V2 官方 harness、systemd/openKylin。
