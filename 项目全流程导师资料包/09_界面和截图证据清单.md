## 9.1 截图保存建议

建议新建一个本地目录：

```text
D:\Luo_docs\竞赛\研创赛\memguardos\答辩截图\
```

按上表文件名保存。不要把私人密码、真实 token、真实 API key、真实主机敏感路径截进去。如果截图里出现 token，请打码。

## 9.2 截图答辩顺序

建议答辩展示顺序：

1. Git HEAD 和 pytest，证明版本和测试。
2. Web 控制台总览，证明可操作界面。
3. 写入、检索、RAG、遗忘，证明核心功能。
4. 审计链、敏感阻断，证明安全治理。
5. openKylin systemd/cgroup/Kylin SDK/Peony/UKUI，证明 OS 机制。
6. 提交包审计，证明交付完整。
