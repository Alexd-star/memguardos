# 04 运行流程

## 4.1 人话版运行流程

你可以把 MemGuardOS 想成一个“AI 助手的本地记忆管家”。它的工作流程是：

1. 你或 Agent 给它一段内容，比如“以后回答 Linux 命令时先给命令，再提醒风险”。
2. 它先检查这段内容质量是否太差，比如空文本、乱码、重复无意义内容。
3. 它再检查里面有没有敏感信息，比如手机号、API key、私钥、`.ssh/id_rsa` 这类路径。
4. 如果是高风险敏感内容，它直接拒绝长期保存；如果是中低风险，它先脱敏再保存。
5. 它判断这条内容是偏好、知识还是安全策略，并提取摘要、实体和关系。
6. 它把完整版本写入追加式段文件，把可检索元数据写入 SQLite。
7. 当 Agent 需要回答问题时，它会搜索相关记忆，构建一个已脱敏、带解释信息的上下文包。
8. 如果用户说“忘掉某类信息”，它先找候选给你看；你确认后，它写 tombstone，清理索引，执行 compact，再验证旧明文是否还存在。
9. 每个关键动作都会写审计记录，审计记录用哈希链串起来，可以用 `verify-audit` 检查有没有被篡改。

## 4.2 技术版运行流程

以 `memctl ingest --text "以后回答 Linux 命令时直接给命令和风险提示。"` 为例：

1. 命令进入 `memguard/cli/memctl.py` 的 `main()`。
2. `main()` 创建 `MemGuardService`。
3. `MemGuardService.__init__()` 初始化：
   - `AppendOnlyMemoryStore`
   - `SQLiteMetaStore`
   - `SensitiveDetector`
   - `HybridMemoryExtractor`
   - `HybridRetriever`
   - `ForgetPlanner`
4. `ingest_text()` 调用 `assess_text_quality()` 做输入质量检查。
5. `SensitiveDetector.classify()` 判断敏感等级。
6. 如果需要脱敏，调用 `SensitiveDetector.redact()`。
7. `HybridMemoryExtractor.extract()` 判断记忆类型和子类型。
8. `make_memory()` 创建 `MemoryRecord`。
9. `_enrich_graph()` 提取实体和关系。
10. `AppendOnlyMemoryStore.append()` 追加写入段文件。
11. `SQLiteMetaStore.upsert_memory()` 写入元数据、FTS 和图谱关系。
12. `_audit()` 写入审计哈希链。
13. CLI 把 JSON 结果打印到终端。

## 4.3 文件/函数调用链

### 4.3.1 写入调用链

```text
memguard/cli/memctl.py::main
  -> MemGuardService(...)
  -> MemguardService.ingest_text
      -> memguard/ingestion/quality.py::assess_text_quality
      -> memguard/sensitivity/detector.py::SensitiveDetector.classify
      -> memguard/sensitivity/detector.py::SensitiveDetector.redact
      -> memguard/extraction/semantic.py::HybridMemoryExtractor.extract
      -> memguard/models.py::make_memory
      -> memguard/extraction/entity.py::extract_entities / extract_relations
      -> memguard/store/mmap_store.py::AppendOnlyMemoryStore.append
      -> memguard/store/sqlite_meta.py::SQLiteMetaStore.upsert_memory
      -> memguard/store/sqlite_meta.py::SQLiteMetaStore.add_audit
  -> print JSON
```

### 4.3.2 检索调用链

```text
memguard/cli/memctl.py::main
  -> MemGuardService.search
      -> SQLiteMetaStore.search_text
      -> HybridRetriever.rank
      -> SQLiteMetaStore.graph_search / related_memories
      -> ConflictResolver.resolve
      -> _audit("search")
  -> print JSON
```

### 4.3.3 RAG 上下文调用链

```text
memguard/cli/memctl.py::main
  -> MemGuardService.build_context
      -> MemGuardService.search
      -> 敏感等级过滤与脱敏
      -> token 预算估算
      -> 来源分布、类型分布、层级分布统计
      -> selection_trace 生成
      -> _audit("build_context")
  -> print JSON context package
```

### 4.3.4 精准遗忘调用链

```text
memguard/cli/memctl.py::main
  -> MemGuardService.forget
      -> ForgetPlanner.plan
      -> 如果 confirm=false：只返回候选
      -> 如果 confirm=true：
          -> AppendOnlyMemoryStore.tombstone
          -> SQLiteMetaStore.mark_deleted
          -> SQLite FTS 删除
          -> 图谱关系删除
          -> 可选 MemGuardService.compact
          -> _audit("forget")
  -> verify_forget_probe 检查残留
```

### 4.3.5 Web 控制台调用链

```text
memguard/cli/memctl.py::main web
  -> memguard/web/dashboard.py::run_dashboard
  -> 浏览器访问 127.0.0.1:8765
  -> _DashboardHandler.do_GET / do_POST
  -> _authorized 校验 Bearer Token
  -> handle_request 或直接 service 方法
  -> MemGuardService 核心逻辑
  -> JSON/HTML 响应
```

## 4.4 文字流程图

```text
输入数据
  |
  v
质量校验
  |-- 不合格 -> 拒绝写入 + 审计 quality_reject
  |
  v
敏感检测
  |-- high -> 拒绝写入 + 审计 sensitive_block
  |-- medium/low -> 脱敏后继续
  |-- none -> 原文继续
  |
  v
语义抽取
  |-- preference
  |-- knowledge
  |-- sensitive_policy
  |
  v
实体/关系抽取
  |
  v
存储
  |-- mmap 段文件保存完整版本
  |-- SQLite 保存元数据、FTS、图谱、审计
  |
  v
检索/RAG/遗忘
  |-- search -> 返回排序结果
  |-- build-context -> 返回上下文包和解释信息
  |-- forget -> 候选 -> 确认 -> tombstone -> compact -> verify
  |
  v
审计链校验 verify-audit
```

## 4.5 启动项目的三种方式

### 方式一：CLI 单次命令

适合学习和截图。每运行一个命令，程序启动一次，完成后退出。

```powershell
python -m memguard.cli.memctl doctor
python -m memguard.cli.memctl ingest --text "以后回答 Linux 命令时先给命令。"
python -m memguard.cli.memctl search "Linux 命令"
```

### 方式二：Web 控制台

适合展示给评委看。

```powershell
python -m memguard.cli.memctl web --host 127.0.0.1 --port 8765
```

打开浏览器访问：

```text
http://127.0.0.1:8765
```

### 方式三：systemd daemon

适合 openKylin 复验操作系统机制。

```bash
sudo bash scripts/install_openkylin.sh "$(pwd)"
sudo systemctl start memguardd
systemctl status memguardd --no-pager
```
