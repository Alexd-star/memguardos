# MemGuardOS 项目全流程导师资料包

本资料包是给“几乎从零接手项目的人”看的。它不假设你已经懂操作系统、智能体记忆、RAG、审计链、Kylin SDK 或项目代码，而是按“赛题是什么、项目做了什么、代码在哪里、怎么运行、怎么截图、怎么答辩”的顺序讲清楚。

当前资料包基于仓库当前状态整理，核验时间为 2026-06-07，当前 Git HEAD 为 `e0f0a7d`。本地最新验证结果为 `python -m pytest -q` 输出 `70 passed`，竞赛就绪自检输出 `136/136 passed`。openKylin 最新证据目录为 `docs/evidence/latest/`，其中证据包记录的 openKylin 单元测试为 `68 passed`，10k 负载检索 P95 为 `10.844 ms`，P99 为 `106.095 ms`，RSS 为 `149284 KB`。
