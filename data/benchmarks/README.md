# Benchmark 数据治理说明

本目录保存 MemGuardOS 的可复现评测数据。每个 JSONL 文件一行一个对象，标签用于把检索结果映射到稳定的期望语义，不等同于运行时 `memory_id`。

## 标注规则

- 检索用例只把语义上应保留的规范记忆列为 `expected`。
- 同义或近重复记忆必须先合并为一个规范标签，不能要求检索器命中某个随机副本。
- hard negative 应与查询共享表面词，但在作用域、时间、主体、行为结果或安全语义上不成立。
- shell history、auditd 和工具日志属于观察证据；除非存在结果事件或用户确认，不能据此宣称 Agent 已执行命令或形成长期偏好。
- 精准遗忘用例同时声明 `expected_delete` 与 `expected_keep`，防止只追求召回而扩大删除范围。

## 可复现性

正式评测报告记录数据文件 SHA256、Git 源修订、原始逐轮结果和门禁阈值。修改样例时必须同步更新测试、说明和新证据，不覆盖历史证据中的旧数据哈希。

2026 年 7 月的数据治理修订移除了一组不可判定的高风险 shell 同义标签：两条同义查询统一指向规范策略 `pref_real_shell_danger_confirm`，原重复槽位改为来源边界难例 `knowledge_shell_history_observation_boundary`。用例数量没有减少，且新增了“观察到命令不等于 Agent 执行”的抗误判约束。
